### 👨‍💻 About Me
 
I'm an AI Engineer with 2.5 years of experience building production-grade agentic systems, RAG pipelines, and fine-tuned models at Occams Advisory and Bobble AI. I don't just prototype. I own the full arc from architecture to deployment to monitoring. My work has generated 16,000+ qualified leads autonomously, cut chatbot latency by 75%, and reduced infrastructure costs by 90%. Currently building multi-agent orchestration systems and exploring LLM observability and MCP server development.

### 🚀 What I've Built
 
| Project | What it does | Stack | Impact |
|---|---|---|---|
| **Multi-Agent Lead Gen** | Autonomous outreach across Reddit + LinkedIn, zero humans in the loop | n8n, OpenAI SDK, webhooks | 16,000+ leads in 45 days |
| **Business Incorporation Chatbot** | 4-agent system handling LLC/C-Corp/S-Corp end to end including Stripe payment | OpenAI Agent SDK, FastAPI, React | 75% latency reduction (60s to 15s) |
| **AI CFO System** | Ingests QuickBooks data, computes 70+ financial metrics, generates board reports, automates AR collections | Python, QBO API, Stripe, LLM | 80% reliability improvement |
| **RAFT-backed RAG Assistant** | On-prem financial reasoning with low hallucination on regulatory data | LLaMA-8B, ChromaDB, FastMCP, DPO | Near-zero hallucination rate |
| **LoRA Indic Translation** | PEFT fine-tuned model for Indic language translation | Unsloth, HuggingFace, PyTorch | +33.4% over base model (BLEU + chrF) |
| **AI Influencer Pipeline** | Image + script in, marketing video out, fully automated | SDXL, Flux, diffusion models | 90% infra cost reduction |
